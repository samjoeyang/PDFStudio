PDF Studio

本地优先的桌面 PDF 工作台。合并、重排、批注与签章、矢量 / 栅格双模式水印、文字提取与离线 OCR、身份证排版、压缩优化——所有处理都在本机完成，离线也能用。

核心功能

面向日常文档处理的桌面工具箱，界面直观、即拖即用。

🗂️

合并 · 重排 · 拆分 · 旋转

把多个 PDF 拖入工作区，按网格顺序即最终导出顺序；支持框选、Shift 连选、拖拽排序、整页旋转与删除，仅导出选中页即可完成拆分。

✍️

批注与签章

双击页面添加批注、手绘签名或上传签章，可选择「签名 / 公章」类型；公章自动锁定标准正方形并支持整体缩放，按页独立保存，导出时叠加到 PDF。

💧

水印

文字 / 图片水印，支持全部页或仅选中页、平铺 / 单幅、透明度与旋转，实时预览。两种烘焙方式：矢量（PDF 原生层叠加，保留文字可选中可搜索、文件更小）与栅格化（与压缩 / 批注共用路径）。

🔍

文字提取与 OCR

内置 tesseract.js 与中英文语言包，完全离线运行。新增自适应多路线比对（预处理 / 纠偏 / 版面模式）与中文标点、数字编码纠错，把扫描件识别为可搜索、可复制的文字层，无需联网。

🪪

身份证排版

一键把身份证正反面排版成标准 A4 扫描件 PDF，自动检测版式，省去手动拼贴。

🗜️

压缩与体积优化

图像重编码压缩（可调 DPI 与 JPEG 质量）大幅减小扫描件体积；另提供对象流与元数据清理，轻松瘦身。

↩️

撤销 / 重做

完整的历史记录栈，Ctrl / ⌘ + Z 撤销、Shift 连按重做，误操作随时回退。

🔒

隐私优先

纯本地运行，文档不上传任何服务器；OCR 引擎与语言包随应用内置，断网照常工作。

安装与使用

下载对应系统的安装包，按提示安装即可。下面是各平台的简要步骤。

🍎 macOS

  1. 下载 Apple 芯片（M 系列）或 Intel 版本的 .dmg。
  2. 打开 .dmg，把 PDF Studio 拖入「应用程序」文件夹。
  3. 首次打开若提示“无法验证开发者”，在系统设置 → 隐私与安全性中点击「仍要打开」。
  4. 直接把 PDF 拖进窗口，或点击「打开 PDF」开始处理。

提示：未签名版本会被 Gatekeeper 拦截，属正常现象；如需消除提示可对应用进行签名与公证。

🪟 Windows

  1. 64 位系统下载 .msi（推荐）或 .exe 便携版；32 位系统请下载标注 x86 的版本。
  2. 双击安装包按向导完成安装（便携版可直接运行，无需安装）。
  3. 若 SmartScreen 拦截，点击「更多信息 → 仍要运行」。
  4. 启动后在窗口中打开或拖入 PDF 即可。

🐧 Linux

  1. 下载 .AppImage（推荐，免安装）或 .deb 包。
  2. AppImage：chmod +x PDFStudio-*.AppImage 后双击运行；deb：sudo dpkg -i PDFStudio-*.deb。
  3. 如缺依赖，按提示安装 libwebkit2gtk-4.1 等运行库。

通用技巧

  • 把多个 PDF 直接拖入主窗口即可合并，页面网格顺序 = 导出顺序。
  • 框选页面后点击「导出选中」即可拆分/提取；Shift 连选、Ctrl/⌘ 多选。
  • 双击页面卡片添加批注与签章（签名 / 公章）；Delete 删除选中页。
  • 水印选「矢量」模式时，导出后页面文字仍可选中 / 搜索且体积更小；「栅格化」则整页转为图片，与压缩、批注兼容。
  • 扫描件识别可在设置中开启「自适应比对多种识别路线」提升准确率，多页文档会更耗时。
  • 导出时可开启「优化体积」与「图像重编码压缩」减小文件。
