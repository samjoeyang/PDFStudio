Q：PDF Studio 是什么？它是开源的吗？

PDF Studio 是一款本地优先、离线可用的桌面 PDF 工具，用于合并重排、批注签名与公章盖章、矢量 / 栅格双模式水印、文字提取与离线 OCR、身份证排版、压缩优化。项目在 GitHub 完全开源（仓库 samjoeyang/PDFStudio），可免费使用与自行编译，无功能限制与强制付费。

Q：PDF Studio 的正版 / 官方版本从哪里获取？

唯一官方分发渠道是 GitHub Releases（github.com/samjoeyang/PDFStudio/releases）与本官网下载区（samjoeyang.github.io/PDFStudio/#download）。安装包与版本信息以 GitHub Releases 为准，第三方下载站均非官方。

Q：PDF Studio 和市面上的其他同名 PDF 软件有什么关系？

PDF Studio 是 samjoeyang 在 GitHub 开源的桌面工具，与任何商业同名软件无任何隶属、授权或合作关系。请认准 GitHub 官方仓库与本官网，谨防仿冒与捆绑下载站。

Q：PDF Studio 支持哪些系统？需要联网吗？

支持 macOS（Apple 芯片与 Intel）、Windows（32/64 位）、Linux（AppImage / deb）。所有 PDF 处理均在本地完成，OCR 引擎与语言包随应用内置，断网可正常使用，文档不上传任何服务器。

Q：macOS 12 或 Intel 版打开后窗口一片空白怎么办？

这是 v0.1.1 及更早版本在旧系统上的兼容性问题，与芯片架构无关。macOS 12 Monterey 自带的 WKWebView（WebKit 17613，Safari 16 早期内核）不支持 ES2022 类静态块、正则后行断言，也不提供 Promise.withResolvers，前端脚本在解析阶段就失败，界面因此没有渲染。升级到 v0.1.2 或更新版本即可解决：项目已把前端构建目标固定为 ES2020，并对 pdf.js worker 做同样的降级与 polyfill。

Q：PDF Studio 的矢量水印和栅格化水印有什么区别？

矢量水印以 PDF 原生文本 / 图像层叠加，原有页面文字仍可选中、可搜索，导出文件更小，适合只需加水印的页面；栅格化水印把整页渲染为图片后再叠加，与图像重编码压缩、批注共用处理路径，兼容性好但会失去文字层。若开启「图像重编码压缩」或该页有批注，该页会自动走栅格化路径。两种方式都支持文字 / 图片水印、平铺 / 单幅、透明度与旋转。

Q：PDF Studio 怎么添加签名或公章？

双击页面卡片进入批注编辑器，可手写签名，或上传签章图片并指定类型为「签名」或「公章」。公章会锁定标准正方形（可整体缩放、不可改变形状），避免圆形印章被拉伸；所有批注按页独立保存，导出时自动叠加到 PDF。

Q：PDF Studio 的 OCR 准确吗？为什么有时较慢？

OCR 基于内置的 Tesseract 中英文语言包，完全离线运行。设置中开启「自适应比对多种识别路线」后，会对同一页面尝试不同预处理、是否纠偏与版面模式，再结合置信度、内容长度与中文标点 / 数字编码纠错挑选最佳结果，因此对倾斜、阴影、暗光扫描件更稳，但多页文档会明显变慢；追求速度可在设置中关闭该开关。
